# Brand logos (optional)

Put **official** logo files here to replace the faint wordmarks in the Overview header:

    anthropic.svg  deepseek.svg  google.svg  openai.svg  xai.svg     (or .png)

Use only files from each company's own brand / press kit and follow its usage guidelines.
The app never draws or downloads logos itself. Files are shown faintly (22% opacity) as decoration.
Restart Streamlit after adding or replacing a file.

Current files: monochrome brand icons from Lobe Icons (`@lobehub/icons-static-svg`, MIT licence for the
package; the marks remain trademarks of their owners). `google.svg` is the Gemini icon. Replace any file
with the official asset from the company's brand kit if you prefer.
